# Blank Practice Notebooks

These notebooks are **empty templates** designed for live coding interviews. Each has:
- Problem descriptions in markdown
- Empty code cells with helpful comments
- Logical structure to guide your solutions

## Usage

1. Open a notebook in Jupyter or VS Code
2. Read the problem description
3. Write your solution in the empty code cells
4. Run and test your code

## Notebooks

- **blank_data_cleaning.ipynb** - Handle duplicates, nulls, string transformations
- **blank_joins_aggregations.ipynb** - Join DataFrames, perform aggregations
- **blank_window_functions.ipynb** - Ranking, running totals, moving averages
- **blank_performance.ipynb** - Optimize partitioning, caching, broadcast joins
- **blank_sql_operations.ipynb** - Write complex SQL queries
- **blank_udfs.ipynb** - Create and optimize user-defined functions
- **blank_real_world_scenario.ipynb** - Complete e-commerce analytics problem

## Tips

- Import libraries in the first cell
- Create SparkSession early
- Show your work with `.show()` or `.explain()`
- Comment your code for the interviewer
- Think out loud about trade-offs
