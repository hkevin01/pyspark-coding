## How to Use

**Jupyter Notebooks (Recommended):**
- Rich markdown explanations
- Run code interactively
- See outputs inline

**Python Scripts:**
- Run from command line: `python 01_data_manipulation_questions.py`
- Good for quick reference
- All questions execute sequentially

## Study Tips

1. Read the question carefully
2. Try solving it yourself first (use blank_practice notebooks)
3. Compare your solution with the provided one
4. Understand the time/space complexity
5. Note the PySpark idioms and patterns used
