# PySpark Intermediate Track 💪

Level up your Spark skills with advanced operations and patterns.

## Prerequisites
✅ Complete beginner track first  
✅ Comfortable with DataFrames  
✅ Understand joins and aggregations  

## Learning Path (5 modules, ~3 hours)

### 01. Advanced Transformations ⭐⭐⭐☆☆
**Time:** 35 minutes | **Difficulty:** 3/5
- Complex withColumn operations
- Conditional logic (when/otherwise)
- Date operations and calculated metrics
```bash
python 01_advanced_transformations.py
```

### 02. Window Functions ⭐⭐⭐⭐☆
**Time:** 40 minutes | **Difficulty:** 4/5
- Ranking (row_number, rank, dense_rank)
- Lag/lead for time series
- Running totals and moving averages
```bash
python 02_window_functions.py
```

### 03. User Defined Functions ⭐⭐⭐⭐☆
**Time:** 35 minutes | **Difficulty:** 4/5
- Python UDFs (basic)
- Pandas UDFs (vectorized, fast!)
- Performance comparison
```bash
python 03_user_defined_functions.py
```

### 04. Aggregation Patterns ⭐⭐⭐⭐☆
**Time:** 35 minutes | **Difficulty:** 4/5
- Multiple aggregations
- Pivot tables
- Rollup and cube operations
```bash
python 04_aggregation_patterns.py
```

### 05. Data Quality Framework ⭐⭐⭐⭐☆
**Time:** 40 minutes | **Difficulty:** 4/5
- Schema validation
- Null and duplicate detection
- Business rule validation
- Quality reporting
```bash
python 05_data_quality_framework.py
```
